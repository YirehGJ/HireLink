# Formulario de retroalimentación del piloto

Está pensado para pegarse en Microsoft Forms (el equipo ya usa OneDrive) o en cualquier herramienta de formularios. Es
**anónimo**: no pide nombre ni correo, solo un código de participante que entrega el moderador (por ejemplo `C03` para el
tercer candidato o `R02` para el segundo reclutador).

   «No», el formulario termina)*

## Sección 3. Facilidad de uso (escala SUS)

Responde del 1 («Totalmente en desacuerdo») al 5 («Totalmente de acuerdo»).

| # | Afirmación |
|---|---|
| 5 | Creo que me gustaría usar HireLink con frecuencia |
| 6 | Encontré HireLink innecesariamente complejo |
| 7 | Pensé que HireLink era fácil de usar |
| 8 | Creo que necesitaría ayuda de una persona con conocimientos técnicos para usar HireLink |
| 9 | Encontré que las funciones de HireLink estaban bien integradas |
| 10 | Pensé que había demasiada inconsistencia en HireLink |
| 11 | Imagino que la mayoría de las personas aprendería a usar HireLink muy rápido |
| 12 | Encontré HireLink muy incómodo de usar |
| 13 | Me sentí muy seguro(a) usando HireLink |
| 14 | Necesité aprender muchas cosas antes de poder usar HireLink |

### Cómo se calcula el puntaje SUS

- Preguntas impares de la escala (5, 7, 9, 11, 13): puntaje = respuesta − 1.
- Preguntas pares de la escala (6, 8, 10, 12, 14): puntaje = 5 − respuesta.
- Se suman los 10 puntajes y se multiplican por 2.5. El resultado va de 0 a 100; 68 es el promedio de referencia.
