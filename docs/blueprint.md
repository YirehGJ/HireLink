# **App Name**: HireLink

## Core Features:

- User Authentication: User authentication and role-based access control (RBAC) for candidates, recruiters, and administrators.
- Candidate Profile Management: Candidate profile creation and editing with fields for headline, location, years of experience, availability, and skills management.
- Job Posting and Management: Job posting and management for recruiters, including a Markdown editor for job descriptions and fields for location, remote work options, contract type, and seniority level.
- Recommendation Feed: Recommendation feed for candidates displaying job title, location, match percentage, and reasons for the recommendation. Recruiters are able to create/edit job openings.
- CV Analysis: AI-powered CV analysis to extract skills and populate candidate profiles. The LLM will act as a tool to extract structured profile information.
- Reason Visualization: Display visualizable reasons for job recommendation match to candidates and recruiters in the form of chips.
- Application Management: Shortlist generation that filters applications using AI powered job match, as well as enables scheduling of interviews and internal note taking for recruiters.

## Style Guidelines:

- Primary color: Blue (#2563EB) for buttons and links to represent trust and professionalism.
- Accent color: Purple (#9333EA) for chips and accents, providing a modern and sophisticated feel.
- Background color: Light gray (#F3F4F6) for a clean and neutral backdrop that emphasizes content, or Dark gray (#111827) for a professional yet subdued look
- Body font: 'Inter' (sans-serif) for UI to maintain readability and a modern appearance. Note: currently only Google Fonts are supported.
- Headline font: 'Nunito' (sans-serif) for headers to create a clear visual hierarchy and add a touch of warmth.
- Use a consistent set of icons, with simple, clear designs.
- Cards should have 16px rounded corners and a soft shadow for a modern and clean look.
- Subtle animations (≤200ms) on hover/press actions and toast notifications for success/error messages.
